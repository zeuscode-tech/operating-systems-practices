# Практическая работа №12 — файловая система Linux

## Цель

Исследовать inode, права и ссылки, реализовать резервное копирование и дедупликацию, сравнить методы размещения файлов.

## Уровень A

`setup_demo.sh` создаёт дерево файлов и показывает:

- одинаковый inode у исходного имени и жёсткой ссылки;
- отдельный inode символической ссылки;
- сохранение данных после удаления одного жёсткого имени;
- поломку символической ссылки после удаления её пути;
- права `640`: владелец читает и пишет, группа читает, остальные не имеют доступа;
- поиск через `find -size +1M` и `find -mtime -1`.

Жёсткая ссылка указывает на inode, поэтому не может пересекать границу файловой системы. `rm` удаляет имя; данные освобождаются только после исчезновения последней жёсткой ссылки и открытого дескриптора.

## Уровень B

### Инкрементальный backup

```bash
./backup.sh backup SOURCE BACKUP_DIR
./backup.sh restore BACKUP_DIR TARGET
```

Скрипт использует `rsync -a`, сохраняет права и временные метки, копирует только изменения и ведёт журнал.

### Дедупликация

```bash
python3 dedup.py DIRECTORY
python3 dedup.py DIRECTORY --apply
```

Без `--apply` выполняется безопасный анализ. С ним одинаковые файлы заменяются жёсткими ссылками после сравнения SHA-256.

### Модель размещения

`fs_model.py` сравнивает непрерывное, связанное и индексное размещение по отказам, стоимости произвольного доступа и размеру крупнейшего свободного участка.

`inode_image.sh --run` создаёт временный ext4-образ и демонстрирует исчерпание inode. Скрипт требует Linux/root, использует временный каталог и всегда размонтирует образ через `trap`.

## Уровень C

`memfs.py` реализует FUSE-файловую систему в памяти с операциями `create`, `read`, `write`, `truncate`, `unlink`, `readdir` и счётчиком обращений.

```bash
sudo apt install fuse3 python3-fusepy
mkdir -p mnt
python3 memfs.py mnt
# в другом терминале: echo test > mnt/file; cat mnt/file; rm mnt/file
fusermount3 -u mnt
```

## Автоматическая проверка

```bash
./run_all.sh
```

Переносимая проверка не требует root. Операции с loop/ext4 и FUSE вынесены отдельно, потому что меняют состояние ядра.

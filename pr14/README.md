# Практическая работа №14 — подсистема ввода-вывода

## Цель

Исследовать устройства, стоимость системных вызовов, буферизацию, блокирующий ввод-вывод, page cache и прямой ввод-вывод.

## Уровень A

- `device_inventory.sh` выводит ОС, диски, файловые системы и зарегистрированные устройства.
- `io_benchmark.c` сравнивает миллионы однобайтовых `write`, блочную запись по 64 КиБ и `fwrite`.
- `fifo_wait.py` сравнивает активный опрос с блокирующим ожиданием через selector.

Основная идея: большое число переходов user → kernel обходится дорого. Буферизация объединяет мелкие операции в крупные.

## Уровень B

`cache_benchmark.sh` показывает ускорение повторного чтения благодаря page cache. Флаг `--drop-caches` разрешён только в Linux от root и никогда не включается автоматически.

`direct_io.c` использует `O_DIRECT`: размер и адрес буфера выровнены по 4096 байт. Прямой ввод-вывод обходит page cache, но накладывает строгие требования и полезен не во всех задачах.

## Уровень C

В `kernel_module/` находится минимальный GPL-модуль символьного устройства. Его загрузка требует отдельной Ubuntu VM и заголовков текущего ядра; команды приведены в локальном README.

## Запуск

```bash
./device_inventory.sh
./run_all.sh
./cache_benchmark.sh
```

Все временные файлы удаляются. Модуль ядра автоматической проверкой не загружается.

# Практическая работа №16 — итоговая защита курса

## Цель

Собрать доказательства выполнения практических работ, повторить ключевые темы и проверить репозиторий перед защитой.

## Что подготовлено

- [DEFENSE_CHECKLIST.md](DEFENSE_CHECKLIST.md) — порядок демонстрации работ;
- [RK2_PREP.md](RK2_PREP.md) — краткая теория и типовые вопросы;
- `check_submission.py` — проверка наличия всех ПР и основных артефактов;
- корневой `check_all.py` — запуск реальных тестов и контроль ссылок/синтаксиса.

## Запуск

Из корня репозитория:

```bash
python3 check_all.py
python3 pr16/check_submission.py
```

## Формат защиты

1. Назвать проблему и цель работы.
2. Показать один ключевой фрагмент кода.
3. Запустить воспроизводимую команду.
4. Объяснить числа в результате, а не только показать их.
5. Сформулировать ограничение решения и вывод.

Привилегированные демонстрации (модуль ядра, FUSE, loop‑mount, users/groups, namespaces) запускаются только в учебной Ubuntu. В автоматической проверке анализируются их код и инструкции, но состояние системы не изменяется.
